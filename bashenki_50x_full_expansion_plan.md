# Башенки — план расширения x50

## Цель

Текущий проект должен вырасти из небольшого TD-прототипа в полноценную долгоживущую single-player Tower Defense игру. Целевая планка — порядка 100 000+ строк реального production-кода, полученных не искусственным дроблением, а большим количеством связанных систем, контента, UI, инструментов, тестов и data-driven логики.

Главный принцип: новая функция должна либо менять решения игрока, либо создавать новый контент, либо связывать несколько существующих систем. Простое увеличение HP, количества файлов или копирование однотипных сущностей не считается расширением.

## Конечная продуктовая модель

Campaign + World Map + Heroes + Towers + Buildings + Economy + Factions + Items + Relics + Runes + Events + Roguelite + Challenges + Endless + Boss Rush + Procedural Maps + NG+ + Endgame + Creator Tools.

- Система не ломает сохранения.
- Система имеет тесты и валидаторы.
- Система создаёт новую стратегическую или реиграбельную ценность.

# 21. ФИНАЛЬНАЯ ПЛАНКА

5 000 строк прототипа должны превратиться не просто в 100 000 строк. Они должны превратиться в игру, в которой один и тот же уровень можно пройти несколькими стратегиями, кампания ведёт через разные регионы и фракции, новые системы постоянно открывают новые варианты прохождения, а после финала остаются roguelite, challenges, Endless, Boss Rush, NG+, procedural content и mastery.

Каждый новый объект должен взаимодействовать с несколькими существующими системами. Башня взаимодействует с врагами, элементами, статусами, технологиями, реликвиями и биомами. Враг взаимодействует с башнями, окружением, маршрутами и событиями. Регион взаимодействует с фракциями, погодой, экономикой и сюжетом. Босс взаимодействует с ареной, героями, башнями и отдельными объектами.

100 000+ строк — следствие реального масштаба продукта, а не самоцель.

Главный gameplay loop:

разведка → выбор героя и билда → строительство → волна → реакция → экономика → выбор усиления → изменение билда → босс → награда → город → прогрессия → новый регион → новый режим → повторное прохождение.

Главный критерий готовности: игрок после первого прохождения должен иметь реальные причины возвращаться — другой билд, другая фракция, другой маршрут, секрет, challenge, реликвия, босс, roguelite-забег, NG+, mastery или новый регион.
