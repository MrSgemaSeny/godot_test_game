# Tower Defense: Люди vs Орки — v2
## Godot 4.7 | Соло | AI-assisted | Глубокая мета-прогрессия

---

## Главная идея

Не просто "поставь башню — убей орка". Игрок строит цивилизацию обороны. Каждое решение в дереве технологий закрывает одни пути и открывает другие. Два игрока с одинаковым скиллом но разными деревьями пройдут одну карту принципиально по-разному.

---

## Три пути развития (выбираешь в начале игры)

Путь нельзя сменить в середине — это и есть реиграбельность.

### Военный путь — "Сталь и кровь"
Ставка на грубую силу. Башни дороже, но убивают быстро.
- Лучники → Арбалетчики → Снайперы (критический урон)
- Баллиста → Осадная пушка → Артиллерия (область + пробивание)
- Уникальная механика: **Берсерк-режим** — раз в волну все башни получают x2 скорость атаки на 10 секунд

### Магический путь — "Знание и контроль"
Ставка на контроль поля. Башни слабее по урону, но орки никогда не доходят быстро.
- Маг льда → Маг времени → Маг пространства (телепортирует орков назад)
- Башня проклятий → Некромант → Личфорж (поднятые орки становятся мини-башнями)
- Уникальная механика: **Аркан-сеть** — башни соединяются в сеть, усиливают друг друга при близком расположении

### Экономический путь — "Золото решает всё"
Меньше башен, но они дешевле и апгрейдятся быстрее. Больше золота с волны.
- Торговый пост → Банк → Казначейство (пассивный доход золота)
- Ловушки → Минное поле → Автоматические турели (дёшево, одноразово)
- Уникальная механика: **Чёрный рынок** — раз в 3 волны появляется случайный мощный предмет за большое золото

## Дерево технологий внутри сессии

Между каждой волной игрок получает 1 очко исследования. Тратит на узлы дерева.

```
                    [Старт]
                       |
          ┌────────────┼────────────┐
     [Оборона]    [Экономика]   [Специальное]
          |             |             |
    [Башни +10%]  [Золото +15%]  [Новый тип башни]
          |             |             |
    [Радиус +20%]  [Продажа 90%]  [Особый навык пути]
          |             |             |
    [Ветка пути]  [Ветка пути]   [Ультимативная башня]
```

Узлы блокируют друг друга — нельзя взять всё. Выбор "Оборона" закрывает часть "Экономики".

## Орки (6 типов + боссы)

| Тип | HP | Скорость | Контрмера |
|-----|----|----------|-----------|
| Рядовой | 100 | Средняя | Любая башня |
| Берсерк | 50 | Очень быстрый | Замедление или AoE |
| Бронированный | 400 | Медленный | Магия (игнор брони) |
| Шаман | 150 | Средняя | Приоритетная цель, лечит других |
| Троль | 1000 | Медленный | Регенерация, нужен burst damage |
| Невидимка | 80 | Быстрый | Только башни с обзором видят |

**Боссы каждые 5 волн:**
- Волна 5: Вождь орков (усиляет всех вокруг)
- Волна 10: Шаман-архимаг (накладывает щиты на орков)
- Волна 15: Горный тролль (раскидывает башни в радиусе)
- Волна 20: Тёмный властелин (финальный босс, меняет маршрут орков)

## Карты (3 штуки)

**Перевал** — один путь, обучающая. Линейно, понятно.

**Болото** — три пути одновременно, орки идут по всем. Нужно делить ресурсы.

**Осаждённый город** — орки появляются с четырёх сторон, в центре крепость. Хаос.

---

## Мета-прогрессия между сессиями

После каждой пройденной карты игрок получает **Очки Славы**. Тратит в глобальном дереве которое сохраняется навсегда.

```
Глобальное дерево:
├── Башни строятся быстрее
├── Начальное золото +50
├── Новый тип орков (сложность)
├── Новая карта
├── Дополнительный слот исследования
└── Секретная башня (открывается последней)
```

## Промпты для старта

### Дерево технологий
```
Godot 4.7, Tower Defense. Напиши tech_tree_manager.gd:
- Данные узлов загружаются из tech_tree.json
- Каждый узел имеет: id, название, описание, стоимость (очки исследования), зависимости (массив id), блокировки (массив id которые закрываются при выборе этого)
- Функция can_unlock(node_id) проверяет: все зависимости куплены, нет активных блокировок, есть очки
- Функция unlock(node_id) применяет эффект узла через сигнал node_unlocked(node_id)
- UI отображает дерево как граф с линиями между узлами
```

### Выбор пути
```
Godot 4.7. Напиши экран выбора пути в начале игры (path_select.tscn).
Три карточки: Военный, Магический, Экономический.
Каждая карточка показывает: название, описание, уникальную механику, список доступных башен.
При выборе — сохраняет путь в GameManager и переходит на game.tscn.
Стиль: тёмное средневековое фэнтези, минималистично.
```

## Подводные камни

**Баланс трёх путей.** Самое сложное — сделать все три пути одинаково жизнеспособными но разными по ощущению. Военный не должен быть просто "лучшим". Тестируй каждый путь отдельно.

**Дерево технологий — данные в JSON, не в коде.** Если захардкодишь узлы в скрипте — будешь переписывать код при каждом изменении баланса. JSON меняется без перекомпиляции.

**Блокировки узлов.** Когда узел A блокирует узел B — убедись что это двусторонне понятно игроку визуально. Иначе игрок случайно закроет себе путь и не поймёт почему.

**Сохранение мета-прогрессии.** Godot имеет встроенный FileAccess для JSON сохранений. Не используй ProjectSettings для хранения прогресса — это для конфигурации, не для данных игрока.
